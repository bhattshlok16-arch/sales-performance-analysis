Sales Performance Analysis
Project Overview

This project analyzes sales transaction data using MySQL and Microsoft Excel.

The goal of the project is to understand sales performance across products, categories, regions, and customer types and present the findings through an Excel dashboard.

Tools Used

MySQL — Data analysis and SQL queries

Microsoft Excel — PivotTables, calculations, charts, and dashboard creation

Dataset

The dataset contains 30 sales transactions with the following fields:

Order ID

Order Date

Product

Category

Region

Quantity

Unit Price

Customer Type

Sales revenue was calculated using:

Quantity × Unit Price

SQL Analysis

The analysis used SQL to answer questions such as:

What are the total sales and number of orders?

Which product generates the most revenue?

Which category generates the most revenue?

Which region has the highest sales?

Which customer type generates the most revenue?

How do customer types perform across different regions?

SQL concepts used include:
